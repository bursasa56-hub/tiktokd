# Инструкция по установке и запуску бота

Спасибо за покупку! Это Telegram-бот для скачивания видео из TikTok и YouTube без водяного знака.

Вы получили полный исходный код бота и устанавливаете его на **свой сервер самостоятельно** — по этой пошаговой инструкции. Программировать ничего не нужно, все команды готовы, установка занимает 10–15 минут.

---

## Что нужно перед запуском

1. **Токен бота** — получить у [@BotFather](https://t.me/BotFather): команда `/newbot`, придумать имя и username (username должен заканчиваться на `bot`). BotFather выдаст токен вида `123456789:AA...`.
2. **Ваш Telegram ID** — узнать у [@userinfobot](https://t.me/userinfobot). Нужен для доступа к админ-панели.
3. **API_ID и API_HASH** — получить на [my.telegram.org](https://my.telegram.org) → войти по номеру телефона → **API development tools** → создать приложение → скопировать `api_id` и `api_hash`. Они нужны для локального Bot API сервера, который поднимает лимит файлов до **2 ГБ**.
4. **Сервер (VPS)** — Ubuntu 22.04/24.04. Для больших видео берите минимум **2 ГБ RAM и 20+ ГБ диска** (~400–600 ₽/мес). Домен и SSL не нужны.

> Если большие файлы не нужны, можно не создавать API_ID/API_HASH: удалите сервис `telegram-bot-api` из `docker-compose.yml` и строку `TELEGRAM_API_URL` из `.env` — тогда бот будет работать через публичный Telegram с лимитом 50 МБ.

## Вариант 1. Запуск через Docker (рекомендуется, для сервера)

### 1. Установить Docker
```bash
apt update && apt install -y docker.io docker-compose-v2
```

### 2. Загрузить файлы бота на сервер
Скопируйте папку с проектом на сервер (через SFTP/WinSCP или `git clone`), например в `/opt/tiktokd`.

### 3. Создать файл `.env`
В папке проекта создайте файл `.env`:
```
BOT_TOKEN=ваш_токен_из_BotFather
ADMIN_IDS=ваш_telegram_id
API_ID=ваш_api_id
API_HASH=ваш_api_hash
```
Можно указать несколько админов через запятую: `ADMIN_IDS=111111,222222`.

Благодаря `API_ID`/`API_HASH` в `docker-compose.yml` запускается дополнительный контейнер `telegram-bot-api` — локальный Bot API сервер. Он поднимает максимальный размер отправляемого файла до **2 ГБ**.

### 4. Запустить
```bash
cd /opt/tiktokd
docker compose up -d --build
```

### 5. Проверить
```bash
docker compose logs -f
```
Если видите `Run polling for bot @...` — бот работает. Выход из логов — `Ctrl+C` (бот продолжит работу).

## Вариант 2. Запуск на компьютере (Windows / Linux)

Нужен Python 3.12 и ffmpeg.

```powershell
# в папке проекта
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```
На Linux вместо `.venv\Scripts\python.exe` используйте `.venv/bin/python`.

## Первичная настройка в Telegram

1. Напишите боту `/start` со своего аккаунта (он должен быть в `ADMIN_IDS`).
2. Появится кнопка **⚙️ Админ-панель**.
3. **Обязательные подписки:** добавьте бота администратором в свой канал → в админке «Добавить подписку» → пришлите `@username` канала или перешлите пост из канала.
4. **Рассылка:** админка → «Рассылка» → пришлите пост → подтвердите.

## Как пользоваться

Отправьте боту ссылку на видео из TikTok или YouTube — он скачает и пришлёт файл. Работает и в личке, и в группах.

## Возможные проблемы

| Проблема | Решение |
|---|---|
| Бот не отвечает | Проверьте `docker compose logs -f`, убедитесь что токен верный и контейнеры запущены (`docker compose ps`) |
| «Видео слишком большое» | С локальным Bot API сервером лимит — 2 ГБ. Если лимит 50 МБ — проверьте, что в `.env` указан `API_ID`/`API_HASH`, а в `docker-compose.yml` есть сервис `telegram-bot-api` и переменная `TELEGRAM_API_URL` |
| Не запускается `telegram-bot-api` | Проверьте логи `docker compose logs telegram-bot-api` — чаще всего неверные `API_ID`/`API_HASH` |
| Видео скачивается долго | Большие файлы (сотни МБ) качаются долго — это нормально, дождитесь окончания |
| «Видео недоступно» | Пост удалён, скрыт или ограничен по возрасту |
| TikTok не скачивается | Сервис иногда блокирует серверы по IP — попробуйте позже или другое видео |
| Не проверяются подписки | Бот должен быть **администратором** в канале |
